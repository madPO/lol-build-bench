# LoL Build Bench

LoL Build Bench is a web application for generating and testing builds for the game League of Legends. Users can select champions, modify items and runes, or generate builds based on champion strengths. The application also provides a graph with stats for completed builds.

## Project Structure

- `src/frontend`: Contains the frontend code for the application.
- `src/backend`: Contains the backend code for the application.
- `docker`: Contains Docker configurations for the project.

## Features

- Select a champion and customize builds.
- Generate builds based on champion strengths.
- View stats for completed builds in a graph.
- Update game data (runes, items, champions, stats) from the latest patch.

## Getting Started

1. Clone the repository.
2. Navigate to the `src/frontend` and `src/backend` directories to set up the respective projects.
3. Use the `docker` directory for containerization and deployment.
